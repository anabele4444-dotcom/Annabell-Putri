# Latihan Git & GitHub

Tugas ini berisi catatan dan alur pengerjaan tugas penggunaan dasar Git Bash dan mengelola repository GitHub

## Alur Pengerjaan & Aktivitas Git

Berikut adalah perintah yang telah dilakukan dalam repository ini:

1. * Melakukan inisialisasi awal repository di Git Bash

2. * Membuat file baru
   * Mengedit isi file
   * Mengubah nama file (rename)
   * Menyalin file (copy)
   * Menghapus file hasil salinan (delete copy)

3. Branch
   * Membuat branch baru bernama `branch-coba-coba`
   * Menambahkan file baru ke dalam `branch-coba-coba`
4. Merge Branch
   * Melakukan merge untuk menggabungkan seluruh perubahan dari `branch-coba-coba` ke branch (`main`)
